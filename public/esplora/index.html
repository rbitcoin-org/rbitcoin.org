Plain HTTP on --esplora-listen (default off). TLS is a reverse proxy's job. Behavior and intentional differences are owned by COMPAT.md; this file describes the request and response shapes. If the two disagree, COMPAT.md and the router in crates/rbitcoin-esplora/src/server.rs win.

Hashes

Every txid and block hash is 64 hex characters in display order (the order Core and Esplora print). A scripthash is SHA256(scriptPubKey) in digest order, not reversed. a-f and A-F are both accepted, as is an optional 0x or 0X prefix. A malformed hash in a path or in ?asof= returns 404 Not Found.

Stored block reads

Hash-addressed block routes admit active blocks and blocks disconnected during the current process. Header-only and never-connected bodies are 404. Restart forgets disconnected membership: reopened stale blocks are 404 until reconnected and disconnected again. This does not relax ?asof=.

Chain-view headers

Pinned responses carry X-Bitcoin-Chain-Tip (block hash) and X-Bitcoin-Chain-Tip-Height. Both are CORS-exposed. Block, tx, and header routes stamp the live tip. /address/*, /scripthash/*, /addresses/*, /scripthashes/*, /internal/address/*, and /internal/scripthash/* (with their /history) stamp the scripthash-index watermark, so the JSON matches the join that produced it, except /address/{address}/txs/mempool and /scripthash/{scripthash}/txs/mempool, which are not stamped. With ?asof=, the stamp is the as-of block. Public /mempool, /mempool/txids, /mempool/recent, and /mempool/removed are not stamped. /mempool/txids/page and /mempool/txids/page/{last_txid} are, because the unstamped check is only /mempool and /mempool/{one segment}. /fee-estimates, POST /tx, and POST /txs/package are not stamped. /internal/mempool/* is stamped. If two sequential fetches disagree on the hash, drop the batch and restart. If the pin leaves the best chain mid-request, the response is 503 chain view moved. A handler error on a route that already took a pin still carries the chain-tip headers. A bad ?asof= is rejected before that pin and does not.

X-Powered-By

Every response, including errors, carries X-Powered-By: rbitcoin-esplora/<version>-<hex>. <version> is the crate version. <hex> is that version with each byte written as two hex digits.

As-of (?asof=<blockhash>)

Answers "what did this wallet look like at this block", for a block that is still on the best chain. The confirmed join is pinned at that ancestor: later confirmations are invisible and the mempool is never included. The response headers carry the as-of hash and height.

  • Accepted only on the routes that declare the asof parameter below: /tx/{txid}/status, /tx/{txid}/outspend/{vout}, /tx/{txid}/outspends, and address/scripthash /, /utxo, /txs, /txs/chain[/{last}], /txs/summary[/{last}], the output-by-position routes (/block-height/{height}/tx/{index}[/out/{vout}], /tx/{txid}/out/{vout}, POST /block-heights/txs/outs), plus the unix-socket /internal/address/{address} and /internal/scripthash/{scripthash} and their /history.
  • On any other route, ?asof= is 404 (for example /tx/{txid}, /mempool, /address/{addr}/txs/mempool, and the POST multi-script routes).
  • An empty value, bad hex, an unknown hash, a hash that is not on the best chain, or (for address/scripthash routes) a block ahead of the visible scripthash index is 404. The server does not retry onto a sibling block at the same height, and it never serves a disconnected fork.
  • If the as-of block is reorged out while the request runs, the response is 404 rather than 503.

The Electrum counterpart is a trailing asof:<blockhash> argument, on any negotiated protocol; see COMPAT.md.

Scripthash index

Address and scripthash routes need --sh-index. Without it they return 503 scripthash index disabled. Unpaged stats and /utxo above --max-sh-creates are 503; a short paged history request is still served, while a full newest-first page reads every create and takes the cap. On the unix socket, /internal/address/{address} and /internal/scripthash/{scripthash} answer those stats without the --max-sh-creates 503.

Errors

Error bodies are text/plain. Unknown paths are 404 Not Found.

Spec server: http://127.0.0.1:3000 (--esplora-listen 127.0.0.1:3000).
